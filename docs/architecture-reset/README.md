# Architecture Reset — исторические материалы

Каталог `docs/architecture-reset/progress/` хранит снимки состояния проекта на отдельных этапах перестройки архитектуры

Эти документы нужны для истории решений и не являются нормативным описанием текущего CareerOPS

Актуальную архитектуру определяют в следующем порядке:

1. исполняемый код текущего HEAD
2. SQLAlchemy metadata и Alembic head текущей v2 schema
3. корневой `README.md`
4. актуальные документы в `docs/processing/`

Если progress-документ противоречит текущему коду, схеме или нормативной документации, приоритет имеет текущая архитектура

Исторические файлы не должны использоваться как инструкция для запуска сервисов, источник актуальных env/config knobs или контракт текущих ownership boundaries

Документы, описывающие полностью удалённые механизмы и больше не несущие полезной истории архитектурных решений, могут удаляться из `progress/`
