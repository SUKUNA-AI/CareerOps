# Processing v2 — P2-03 High-Recall Deterministic Filter

The admission filter is a pure deterministic reference layer inside
`careerops_processing.core`. It has exactly two semantic outcomes:

- `KEEP`: safe exclusion was not proven; this is not a match decision.
- `EXCLUDE_PROVEN`: one or more explicit policy-backed exclusions were proven.

The filter is deliberately fail-open for missing, ambiguous, mixed-role, or partially
understood inputs. Every exclusion carries a stable rule id, a namespaced reason code,
the pinned target-policy version, and source-backed evidence.

Current exclusion families cover explicit source unavailability, proven primary-role
disjointness, explicitly forbidden seniority or management contexts, hard work-format
and location conflicts, explicit relocation requirements, configured experience-gap
limits when both facts are known, and configured forbidden contexts with negation
handling.

Technology mentions are not treated as occupations. Remote alternatives prevent a
geographic exclusion when remote work is allowed or work format is unrestricted.
Missing or unresolved work format/location information remains `KEEP`.

This Python implementation is the correctness reference. A future C++ matching core may
execute measured deterministic hot paths only after parity tests prove equivalent
semantics.
